# x402 Swag storefront API

An x402-native e-commerce storefront by ForgeMesh Labs selling physical merchandise (apparel, drinkware, stickers) themed on the x402 protocol. AI agents or humans can complete real physical-goods purchases end-to-end programmatically, paying per-order in USDC on Base via the x402 protocol, or by card via Stripe. Access is gated by payment (HTTP 402) rather than API keys.
