# x402 Swag storefront API
> x402-native e-commerce storefront by ForgeMesh Labs. Physical merch (t-shirts, mugs, stickers) themed on the x402 protocol, purchasable end-to-end by an AI agent or a human. Browsing, cart and checkout-rates are free; orders pay per-order in USDC on Base (eip155:8453) via x402 (HTTP 402), or by card via Stripe. No accounts, no API keys. Cart is stateless (X-Cart-Id header, cart_id body field, or ?cart_id=).

## Catalog (free)
GET /api/products — list products (q, limit, offset)
GET /api/products/{handle} — product detail
GET /api/collections — list collections
GET /api/collections/{handle} — collection detail
GET /api/agent/catalog — full catalog + buy flow in one paid call ($0.05 USDC)

## Cart & checkout (free to build; order pays)
GET /api/cart — read cart (X-Cart-Id)
POST /api/cart/add — add a variant to the cart
GET /api/checkout/rates — shipping/price rates for the cart
POST /api/checkout — create an order from the cart (email + shipping_address)
GET /api/orders/{token} — read an order
POST /api/orders/{token}/pay — pay the order via x402 (HTTP 402 -> pay USDC on Base -> retry)
POST /api/orders/{token}/stripe — create a Stripe card-checkout session instead

## Custom Print Studio
GET /api/custom/menu — printable blanks + options
POST /api/custom/designs — generate an AI design preview ($0.50 USDC)
GET /api/custom/designs/{id} — read a design
POST /api/custom/designs/{id}/regenerate — regenerate ($0.50 USDC)
POST /api/custom/designs/{id}/approve — approve a design for ordering

## ForgeMesh Brief
POST /api/brief/subscribe — subscribe an email to x402 ecosystem intel ($0.001 USDC anti-spam price)

## Payment
- Protocol: x402 (payments over HTTP)
- Network: Base mainnet (eip155:8453)
- Asset: USDC (0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913)
- payTo: 0xf4F7182508895812F235C5D1c47C0cfc89fDAb5B
- Card alternative: Stripe (per order)
